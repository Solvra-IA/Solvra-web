# Código de conducta

## Nuestro compromiso

Nos comprometemos a mantener una colaboración respetuosa, profesional e inclusiva en issues, pull requests y revisiones.

## Comportamientos esperados

- Comunicación clara y constructiva
- Respeto por diferentes puntos de vista
- Feedback centrado en el código y el impacto, no en la persona
- Colaboración orientada a resolver problemas

## Comportamientos no aceptados

- Ataques personales, insultos o acoso
- Comentarios discriminatorios o despectivos
- Publicación de información privada sin permiso

## Aplicación

Los mantenedores pueden moderar o bloquear interacciones que incumplan este código para proteger la salud del proyecto.
