# Política de seguridad

Si detectas una vulnerabilidad, por favor **no** abras un issue público.

## Reporte responsable

Envía la información por email a: `hola@nexus.es`

Incluye:

- Descripción del problema
- Impacto potencial
- Pasos para reproducir
- Evidencia (capturas/logs) si aplica

## Alcance

Esta política aplica a:

- Código de la web pública en este repositorio
- Integración del formulario de contacto (`/api/contact`)

## Tiempos de respuesta

- Confirmación de recepción: objetivo < 72h laborables
- Evaluación inicial: objetivo < 7 días
- Resolución y publicación: según severidad e impacto
