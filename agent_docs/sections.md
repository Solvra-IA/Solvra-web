# Estructura de secciones — Landing Nexus

Orden actual de la home (`app/page.tsx`):

1. **Hero** — Propuesta de valor + CTAs (diagnóstico / servicios).
2. **Servicios** — 4 bloques: diagnóstico, automatización, integración, formación.
3. **Segmentos** — 3 bloques: inmobiliarias, clínicas, servicios profesionales.
4. **Cómo trabajamos** — 4 pasos: diagnóstico → propuesta → implementación → acompañamiento.
5. **Sobre nosotros** — Joint venture con Solfico + diferenciadores.
6. **FAQ** — 5 preguntas frecuentes (precios, herramientas, RGPD, plazos, geografía).
7. **Contacto** — Formulario + info de contacto.

## Criterios
- Máximo 7 secciones en la home. Si algo no aporta, fuera.
- Cada sección con un solo objetivo claro.
- CTA de contacto visible en header + repetido en Hero + sección final.
- Anclas (`#servicios`, `#segmentos`, etc.) para navegación.

## Posibles secciones v2 (no implementadas)
- Casos de éxito (cuando tengamos 2–3 reales).
- Blog / recursos.
- Equipo (foto + bio corta).
